Chrome DevTools MCP × Custom GPT

安全なローカルChrome操作ブリッジ

構成

Custom GPT Actions → Cloudflare Tunnel → Local Agent → Chrome DevTools MCP 1.6.0 → Dedicated Chrome Profile

主要防御

URLシークレット／Bearer認証、ドメイン許可リスト、危険ツール拒否、専用Chromeプロファイル、Networkヘッダー秘匿、JSONL監査ログ。

起動

cp .env.example .env
# secrets と ALLOWED_HOSTS を編集
docker compose up -d --build

GitHub README と docs/setup.md に完全な設定手順があります。
